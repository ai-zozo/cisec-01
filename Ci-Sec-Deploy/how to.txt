==============================================================
 Ci-Sec — מדריך התקנה על שרת חדש (Ubuntu)
==============================================================

מה זה:
מערכת וובית לניהול מצב אבטחת מידע (תורת ההגנה 2.0 + NIST 800-53 + ISO 27001).
רצה כולה בדוקר: PostgreSQL + API (Node) + Frontend (React) + nginx (HTTPS).

--------------------------------------------------------------
דרישות מוקדמות
--------------------------------------------------------------
- שרת Ubuntu (20.04 / 22.04 / 24.04), נקי לגמרי - לא חייב דוקר מותקן מראש.
- חיבור אינטרנט (להורדת Docker וה-images בפעם הראשונה).
- הרשאות sudo / root.
- שטח דיסק פנוי: מומלץ לפחות 5GB (התקנה תופסת ~3-4GB).
- פורט 11445 פנוי (דרכו מתחברים למערכת).

--------------------------------------------------------------
התקנה - שלב אחר שלב
--------------------------------------------------------------
1. העתק את כל תיקיית ההפצה הזו (Ci-Sec-Deploy) אל השרת.
   למשל מתוך Windows עם pscp / WinSCP, או:
       scp -r Ci-Sec-Deploy user@<כתובת-השרת>:/home/user/

2. התחבר לשרת ב-SSH:
       ssh user@<כתובת-השרת>

3. היכנס לתיקייה:
       cd /home/user/Ci-Sec-Deploy

4. הרץ את סקריפט ההתקנה (הוא עושה הכל אוטומטית):
       sudo bash deploy/install.sh

   הסקריפט:
   - מתקין Docker + Docker Compose (אם חסרים).
   - מייצר קובץ .env עם סיסמאות וסודות אקראיים.
   - מייצר תעודת TLS מקומית בתוקף 5 שנים.
   - בונה ומריץ את כל הקונטיינרים.
   - טוען אוטומטית את כל משפחות הבקרה והבקרות.

5. בסיום תופיע הודעת הצלחה. גש בדפדפן אל:
       https://<כתובת-השרת>:11445

   משתמש:  admin
   סיסמה:  Aa123456   (תידרש החלפה בכניסה הראשונה)

   הערה: התעודה מקומית (self-signed) - הדפדפן יציג אזהרה.
   לחץ Advanced -> Proceed כדי להמשיך.

--------------------------------------------------------------
עליה אוטומטית באתחול השרת (מומלץ)
--------------------------------------------------------------
כדי שהמערכת תעלה לבד אחרי כל הפעלה מחדש של השרת:

   sudo systemctl enable docker
   sudo bash -c 'cat > /etc/systemd/system/cisec.service <<EOF
[Unit]
Description=Ci-Sec stack
Requires=docker.service
After=docker.service network-online.target
Wants=network-online.target
[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/home/user/Ci-Sec-Deploy
ExecStart=/usr/bin/docker compose up -d
ExecStop=/usr/bin/docker compose down
TimeoutStartSec=0
[Install]
WantedBy=multi-user.target
EOF'
   sudo systemctl daemon-reload
   sudo systemctl enable cisec.service

(התאם את WorkingDirectory לנתיב האמיתי של התיקייה אם שונה.)

--------------------------------------------------------------
פקודות ניהול שימושיות (מתוך תיקיית ההתקנה)
--------------------------------------------------------------
   sudo docker compose ps              # מצב הקונטיינרים
   sudo docker compose logs -f         # צפייה בלוגים
   sudo docker compose restart         # הפעלה מחדש
   sudo docker compose down            # עצירה (הנתונים נשמרים)
   sudo docker compose up -d           # הפעלה
   sudo docker compose up -d --build   # בנייה מחדש אחרי שינוי קוד

--------------------------------------------------------------
שינוי הפורט (ברירת מחדל 11445)
--------------------------------------------------------------
ערוך את docker-compose.yml, שירות proxy, שורת ports:
       - "11445:11445"
שנה את המספר השמאלי (פורט חיצוני). אין צורך לשנות את ה-nginx.conf.
לאחר השינוי:  sudo docker compose up -d

--------------------------------------------------------------
גיבוי ושחזור
--------------------------------------------------------------
- בתוך המערכת (כאדמין): גלגל שיניים -> גיבוי / שחזור.
  ניתן ליצור snapshot ידני, להוריד עותק למחשב, ולשחזר מ-snapshot או מקובץ.
- גיבוי מסד הנתונים מהשרת ישירות:
       sudo docker exec cisec-db pg_dump -U cisec cisec > backup.sql

--------------------------------------------------------------
שטח דיסק - שחרור מקום
--------------------------------------------------------------
אם הדיסק מתמלא אחרי בניות חוזרות:
       sudo docker builder prune -af     # משחרר קאש בנייה
       sudo docker image prune -f        # מוחק images תלויים

--------------------------------------------------------------
פתרון תקלות
--------------------------------------------------------------
- "הסיסמה לא התקבלה" / לא נכנס: ודא שהשתמשת ב-admin / Aa123456.
- האתר לא נטען: בדוק "sudo docker compose ps" שכל 4 הקונטיינרים Up,
  ושפורט 11445 פתוח בחומת האש (אם קיימת):  sudo ufw allow 11445/tcp
- שגיאת DNS בבנייה (failed to resolve ... docker.io): נסה שוב, או:
       sudo docker pull node:20-slim
       sudo docker pull node:20-alpine
  ואז:  sudo docker compose up -d --build
- ה-API לא עולה: "sudo docker compose logs api" לבדיקת השגיאה.

--------------------------------------------------------------

   client/                 קוד צד-לקוח (React)
   README.md               תיעוד כללי
