# Ci-Sec — מערכת ניהול מצב אבטחת מידע

כלי וובי לאנשי אבטחת מידע להערכה, סקירה, ניהול וטיפול במצב אבטחת המידע בארגון, עם דשבורד הנהלה גרפי. מבוסס על בקרות **תורת ההגנה 2.0** של מערך הסייבר הלאומי, עם מיפוי ל-**NIST 800-53** ו-**ISO 27001**, ועובד לפי מודל **הערכת הסיכונים** שסופק.

## ארכיטקטורה
- **db** — PostgreSQL 16 (אחסון מתמשך, ללא הגבלה).
- **api** — Node.js + Express + Prisma (REST, JWT+bcrypt, חישובי סיכון, גיבוי/שחזור, יצוא אקסל).
- **web** — React (Vite), עברית RTL, דשבורד עם Recharts.
- **proxy** — nginx, HTTPS בלבד על פורט **11445**, תעודה מקומית ל-5 שנים.

כל השירותים רצים בקונטיינרים נפרדים ברשת דוקר ייעודית (`cisec_net`), ותופסים רק את פורט 11445 — כך שניתן להריץ מערכות נוספות על אותו שרת דוקר.

## התקנה (שרת Ubuntu נקי)
```bash
sudo bash deploy/install.sh
```
הסקריפט: מתקין Docker + Compose, מייצר `.env` עם סודות אקראיים, מייצר תעודת TLS ל-5 שנים, ובונה ומריץ את הסטאק.

לאחר ההתקנה:
- כתובת: `https://<כתובת-השרת>:11445`
- משתמש: `admin` · סיסמה: `Aa123456` (תידרש החלפה בכניסה ראשונה).

## הרשאות
| קבוצה | יכולות |
|------|--------|
| admin | הכל — משתמשים, רשתות, גיבוי/שחזור |
| users | עריכת סקרים ברשת המורשית בלבד |
| management | צפייה בדשבורד מנהלים בלבד |
| guest | צפייה בלבד |

## תכונות מרכזיות
- 12 משפחות בקרה + כל הבקרות נטענות אוטומטית לכל סקר חדש.
- חלון בקרה עם 6 טאבים: פרטי בקרה · הערכת סיכון · מיטיגציה · RACI · ניהול משימות · הערכה תקציבית.
- דגל "לא רלוונטי" — מחריג בקרה מכל החישובים, מפת החום והגרפים.
- דשבורד דינמי: KPI, מפת חום 5×5, מפת עכביש (רדאר), פאי החלטות הנהלה/סטטוס, עמודות רמות סיכון, ותצוגות משימות (הנהלה + אישית). כל אלמנט לחיץ ומנווט לבקרה/משפחה.
- ניהול גרסאות לסקר, יצוא לאקסל, גיבוי ידני/מתוזמן ושחזור.
